# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

The Zymatica project takes cryptographic, inference runtime, and consensus security seriously.

If you discover a security vulnerability in:
- The **BN254 Groth16 zk-SNARK circuits** or nullifier generation,
- The **Ed25519 neural swarm consensus** protocol,
- The **FlashAttention-4 / Hyper-KV cache** memory allocators, or
- The **OpenAI/Claude-compatible HTTP API server**,

Please report it responsibly:
- **Email**: `security@zymatica.space`
- **PGP**: Available upon request.

Please allow up to 48 hours for an initial response before public disclosure. Critical security advisories will be published alongside signed patched releases.
